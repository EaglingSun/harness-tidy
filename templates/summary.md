# 화면 요약 형식 (HT-17, 단계마다 20줄 이내)

## 1단계 요약
```
[harness-tidy {VERSION}] {대상} · 모드 {mode} · 원본 {N}줄
진단  ID {있음/없음} · 다중 규칙 줄 {n} · 내부 중복 {n} · 바깥 중복 {n} · lint 후보 {n}
제안  유지 {n} · 수정 {n} · 묶음 {n} · 이동 {n} · 뺄 {n} → 예상 본문 {n}줄 (상한 {n})
결정 필요 ({n}건)
  {ID}  수정  {한 줄 정리본}  ← 원본 {줄}
  {ID}  뺄    {사유 한 구절}  ← {소관 파일:줄}
  [확인필요] 원본 {줄}: {무엇이 불분명한지 한 구절}
전체: docs/reports/{날짜}-harness-tidy/{약어}-규칙-검토.md
답: "승인" 또는 "{ID} 유지/수정/뺄 …"
```
- 결정 필요 항목이 10건을 넘으면 상위 10건만 보이고 "외 n건 — 검토 문서 참고"
- 유지 항목은 나열하지 않는다 (개수만)

## triage 요약 (HT-20)
```
[harness-tidy {VERSION}] triage · 파일 {n}개 · 규칙 {n}줄
힌트  중복? {n} · 충돌? {n} · 일회성? {n} · 모호 {n} · 용어 {n}
제안  기준 {n} · 일회성 {n} · 중복 {n} · 충돌 {n} · 모호 {n} → 유지 {n} · 수정 {n} · 묶음 {n} · 이동 {n} · 뺄 {n}
예상  {n}줄 → {n}줄
결정 필요 ({n}건, 충돌 → 일회성 → 중복 → 모호 순)
  R014  충돌  「{원문 앞 30자}」 ↔ R031  ← 어느 쪽?
  R020  뺄?   일회성(2026-10 배포 건)  ← {파일:줄}
  R033  묶음? R007 과 같은 뜻 → R007 남김
전체: docs/reports/{날짜}-harness-tidy/rules-triage.md
답: "승인" 또는 "R014 위쪽, R020 유지 …"
```
- 충돌 행은 제안 없이 묻는다. 결정 필요가 10건을 넘으면 충돌 전부 + 나머지 상위만 보이고 "외 n건"

## 2단계 요약
```
[harness-tidy {VERSION}] {대상} 정리 완료
본문 {전}줄 → {후}줄 · 규칙 {n}개 (lint {n} · judge {n})
.bak  {경로}.bak
매핑  evals/{대상}/mapping.md  (유지 {n} · 수정 {n} · 묶음 {n} · 이동 {n} · 뺄 {n})
ID    ID 없음 {n} · 변경 유형 오류 {n}  (inventory.py --coverage, 0 이 아니면 넘기지 않는다)
lint  {위반 n건 / 통과} · 용어 {위반 n건 / 통과 / 용어집 없음} (--terms)
콜드  일치 {n} · 어긋남 {n} · 모호 {n}  (evals/{대상}/cold-read.md, 0 이 아니면 넘기지 않는다)
Eval  evals/{대상}/evals.json {n}건 · trigger-eval.json {n}건 · 커버리지 매핑 {n}행 중 {n}행 (나머지 사유 {n})
다음  재기: {넘김 프롬프트 한 줄} — 승인할까요?
```
