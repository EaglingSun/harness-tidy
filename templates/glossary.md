# 용어집 (HT-22)

- 둘 곳: 여러 프로젝트가 쓰면 `~/.claude/glossary.md`, 한 프로젝트만 쓰면 `{프로젝트}/.claude/glossary.md` (프로젝트 쪽이 우선)
- 자동 로드되지 않는다. 정리 · add 때 harness-tidy 가 `inventory.py --terms` 로 검사하고, 규칙 본문에서 용어 뜻이 필요하면 해당 rule · skill 에 "용어는 glossary.md 를 따른다" 1줄을 둔다
- 스크립트는 **첫 표**만 읽는다: 1칸 표준어 · 2칸 쓰지 않을 말(, · / 로 구분). 2칸이 비면 검사하지 않는다
- 영문 변형은 대소문자 무시 · 단어 경계로, 한글 변형은 부분 일치로 찾는다 (표준어 안에 든 변형은 위반 아님). 백틱 안 · 코드 블록은 검사하지 않는다
- 새 용어는 정리 중에 만들지 않는다. 필요하면 [확인필요]로 이 표에 추가할 행을 제안하고 승인 뒤 넣는다

| 표준어 | 쓰지 않을 말 | 뜻 · 경계 |
|---|---|---|
| {결함} | {버그, 이슈} | {기대 동작과 다른 실제 결과. 개선 요청은 포함하지 않는다} |
| {리뷰 보류} | {hold, 블록} | {머지하지 않고 수정을 요청한 상태} |
| {품질 게이트} | {QG, 관문} | {다음 단계로 넘기기 전 반드시 통과할 조건 묶음} |
